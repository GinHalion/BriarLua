BriarLua 开发文档

基于 AndroLua+ / LuaAppX 深度定制。在手机上用 Lua 写安卓应用，支持打包 APK。

简介

BriarLua 是一个基于 AndroLua 和 LuaAppX Pro 衍生二改的 Android 平台轻量级 Lua IDE。它既拥有 Lua 语言简洁优雅的特质，又通过 LuaJava 桥接直接调用绝大部分 Android 原生 API。

相比原版，BriarLua 重写了代码编辑器（支持语法高亮、自定义符号栏、选中内容浮动菜单、API 类名识别跳转）、集成了更完善的打包工具、优化了文件管理器和布局渲染。

每个脚本的入口文件通常为 main.lua，项目根目录下必须包含 init.lua 用于定义应用名称、包名等信息。BriarLua 内嵌 Lua 5.3.3（定制版），本手册的 Lua 语言部分以 5.3 语法为准。

生命周期回调

页面脚本以全局函数的形式接收 Activity 生命周期事件：

变量

Lua 中变量默认是全局的（无需声明即可赋值），全局变量存放在环境表 _G 中。使用 local 声明局部变量，访问局部变量比全局变量更快：

x = 1          -- 全局变量
local y = 2    -- 局部变量，作用域到本块结束

-- 多重赋值：先求值再赋值，可用来交换变量
a, b = 1, 2
a, b = b, a        -- a=2, b=1

-- 未初始化的变量值为 nil
print(z)           -- nil
z = nil          -- 删除全局变量的方式
建议：在 BriarLua 页面脚本中，除生命周期回调等约定函数外，其余一律使用 local，避免污染全局环境、减少内存驻留。

控制结构

-- if 语句
if cond then
  block
elseif cond2 then
  block
else
  block
end

-- while / repeat
while cond do block end
repeat block until cond   -- 循环体至少执行一次

-- 数值 for
for i = 1, 10, 2 do block end   -- 1,3,5,7,9
for i = 10, 1, -1 do block end -- 倒数

-- 泛型 for
for k, v in pairs(t) do block end  -- 遍历所有键
for i, v in ipairs(t) do block end -- 遍历序列 1..#t

break      -- 跳出最内层循环
goto continue  -- 5.2+ 支持 goto（只能跳到本函数后面的标签）
注意：for 的循环变量是局部变量，且在循环内修改不影响步进；ipairs 遇到 nil 空洞即停止。

函数

-- 常规定义（函数名也是变量）
local function add(a, b)
  return a + b
end

-- 多返回值
local function minmax(t)
  return math.min(table.unpack(t)), math.max(table.unpack(t))
end
local lo, hi = minmax({3, 1, 4})

-- 可变参数
local function sum(...)
  local s = 0
  for _, v in ipairs({...}) do s = s + v end
  return s
end

-- select 获取参数个数 / 第 n 个参数
print(select("#", 1, 2, 3))  -- 3

-- 函数是第一类值：可存入表、作为参数传递
local t = { run = function() return "go" end }
print(t.run())

闭包

内层函数可以引用外层函数的局部变量，即使外层已经返回：

local function counter()
  local n = 0
  return function()
    n = n + 1
    return n
  end
end
local next_id = counter()
print(next_id(), next_id())  -- 1  2
BriarLua 中大量回调（onClick、onCreate 等）都是闭包。注意不要在闭包中无限制引用大对象（如整个布局表），页面关闭时及时解除引用。

表

表（Table）是 Lua 唯一的数据结构，可用于实现数组、字典、对象、模块、命名空间等。

-- 数组风格（索引从 1 开始）
local arr = {"A", "B", "C"}

-- 字典风格
local obj = {name = "BriarLua", ver = 1.8}

-- 混合 + 显式索引
local t = {"first", key = "value", [10] = "ten"}

-- 访问：点号与方括号等价
print(arr[1])       --> A
print(obj.name)     --> BriarLua
print(obj["name"])   --> BriarLua

-- 遍历
for i, v in ipairs(arr) do print(i, v) end
for k, v in pairs(obj) do print(k, v) end
#arr 的陷阱：长度运算符 # 只对"序列"（无空洞的 1..n 数组）有定义。带空洞的表请自行维护计数，或用 table.maxn（5.1）/手动遍历。

可见性规则

Lua 使用词法作用域（Lexical Scoping）：局部变量的作用域从声明处开始，到所在块（do...end / 函数体 / 控制结构体）结束为止。

local x = "外层"
do
  local x = "内层"   -- 遮蔽外层同名变量
  print(x)          --> 内层
end
print(x)            --> 外层

-- 内层函数可读取外层局部变量（上值 / upvalue）
local function make()
  local secret = 42
  return function() return secret end
end

常见技巧：用 do...end 包裹初始化代码，让临时变量尽快离开作用域被回收。

元表与元方法

元表（Metatable）允许改变表的行为：算术运算、比较、索引访问、调用等。每个事件对应一个元方法，以双下划线开头：

元方法触发时机
__index读取不存在的键（表或函数，可实现继承）
__newindex向不存在的键赋值
__call把表当函数调用 t(...)
__tostringtostring(t) / print 时的输出
__len#t
__eq / __lt / __le比较运算
__add / __sub / __mul / __div / __mod / __concat ...算术与连接运算
-- 简单的类与继承
local Animal = {}
Animal.__index = Animal

function Animal.new(name)
  return setmetatable({name = name}, Animal)
end

function Animal:speak()          -- 冒号定义：自动接收 self
  return self.name .. " 发出声音"
end

local dog = Animal.new("旺财")
print(dog:speak())                --> 旺财 发出声音

-- __index 链实现继承
local Dog = setmetatable({}, {__index = Animal})
Dog.__index = Dog
function Dog:speak() return self.name .. " 汪汪" end

BriarLua 源码中的典型应用：MyColor 模块通过 __index 把 MyColor.colorPrimary 透明地映射到 Material 颜色查询。

协程

协程（coroutine）是用户态的可挂起函数，适合"分段产出数据"的场景（生成器、状态机）。它与线程不同：任一时刻只有一个协程在运行，且切换只发生在显式调用 yield/resume 处。

local co = coroutine.create(function(a, b)
  print("第一步", a + b)
  local got = coroutine.yield(a * b)   -- 挂起并回传结果
  print("收到主线程数据", got)
  return "结束"
end)

print(coroutine.resume(co, 3, 4))  -- true 7
print(coroutine.resume(co, "hello"))  -- true 结束

-- 生成器风格：wrap 返回的函数直接当作迭代器
local range = coroutine.wrap(function(n)
  for i = 1, n do coroutine.yield(i) end
end)
for v in range do print(v) end
协程不是并行线程：resume 中如果执行了耗时/阻塞操作（网络、sleep），整个应用界面仍会卡住。耗时任务请使用 线程与异步 一节的 task/thread。

垃圾收集

Lua 5.3 采用分步增量式垃圾收集器，自动回收不再被引用的对象（表、函数、userdata 等）。相关接口：

collectgarbage("collect")   -- 执行一次完整 GC 循环
collectgarbage("count")     -- 当前已用内存，单位 KB（返回两个值）
collectgarbage("step")       -- 执行一步增量 GC
collectgarbage("stop")        -- 停止自动 GC（慎用）
collectgarbage("restart")     -- 恢复自动 GC

BriarLua 页面的 onDestroy 中通常这样收尾（框架源码同款写法）：

function onDestroy()
  -- 释放大对象引用、注销监听器、关闭 Cursor 等
  bigTable = nil
  collectgarbage("collect")
  collectgarbage("step")
end
Java 侧对象（userdata）由 Lua GC 与 Java GC 共同管理：Lua 侧包装对象被回收后，Java 对象失去引用，交给系统回收。避免把 Activity/View 存入长生命周期全局表造成泄漏。

错误处理

-- 抛出错误：error(msg, level)，level=1 指向调用处，2 指向调用者的调用处
local function mustNumber(v)
  if type(v) ~= "number" then error("期望 number，得到 " .. type(v), 2) end
  return v
end

-- pcall：保护调用，出错不中断程序
local ok, result = pcall(mustNumber, "abc")
if not ok then print("出错了: " .. result) end

-- xpcall：可附带错误处理函数（如打印调用栈）
local ok2, err = xpcall(mustNumber, debug.traceback, "abc")

-- assert：条件为假时抛错，常用于校验返回值
local f = assert(io.open("/sdcard/test.txt", "r"))

错误对象可以是任意值（字符串、table）。框架约定：错误消息若以 "src:" 开头会被追加源码位置。BriarLua 运行脚本出错时，错误与回溯会显示在日志页（工具 → 日志）。

涉及 Java 调用的代码块建议一律 pcall 包裹：Java 异常会作为 Lua 错误抛出，未捕获时直接中断脚本。

基础函数（basic）

全局基础函数无需 require 即可使用：

print(...)

打印任意个值，制表符分隔。BriarLua 中转发到日志页（工具 → 日志）。

type(v) → string

返回类型名："nil" / "boolean" / "number" / "string" / "table" / "function" / "userdata" / "thread"。

tostring(v) / tonumber(v [, base])

类型转换。tonumber 转换失败返回 nil；支持 2~36 进制（字符串参数时）。

pairs(t) / ipairs(t)

遍历器。pairs 遍历全部键（顺序不定）；ipairs 从 1 递增直到遇到 nil。

next(t [, k])

底层遍历原语，pairs 即由它实现。

select(n, ...) / select("#", ...)

取出第 n 个之后的可变参数 / 统计可变参数个数。

table.unpack(t [, i [, j]])

表展开为多值：print(table.unpack({1,2,3}))。BriarLua 桥接 Java 数组时常用（亦可用 luajava.astable）。

rawget(t, k) / rawset(t, k, v) / rawequal(a, b) / rawlen(t)

绕过元方法直接操作表。

setmetatable(t, mt) / getmetatable(t)

设置 / 读取元表，见 元表与元方法。

assert(v [, msg]) / error(msg [, level]) / pcall(f, ...) / xpcall(f, handler, ...)

错误处理，见 错误处理。

表操作（table）

table.insert(t, [pos,] v)

尾部（或 pos 处）插入元素，pos 版本会移动后续元素。

table.remove(t [, pos])

移除并返回元素，默认末尾。配合 insert 可实现栈 / 队列。

table.concat(t [, sep [, i [, j]]])

把序列连接为字符串，比 .. 循环拼接快得多。

table.sort(t [, comp])

原地排序，默认升序。comp(a, b) 在 a 应排在 b 前时返回 true。排序不稳定。

table.pack(...) / table.unpack(t)

多值 ↔ 表互转；pack 结果带字段 n 记录个数。

local names = {"Charlie", "Alice", "Bob"}
table.sort(names)                       -- 字典序
table.sort(names, function(a, b) return #a < #b end) -- 按长度
table.insert(names, "Dave")            -- 尾插
print(table.concat(names, ", "))    -- Alice, Bob, Dave, Charlie（上次排序结果）

字符串不可变，所有操作返回新串。Lua 正则并非 POSIX 正则，字符类用 % 引导：

-- 替换 + 引用捕获

-- 注意：中文一个字是 3 个 UTF-8 字节，sub 按字节截断可能截出乱码

I/O（io）

BriarLua 继承完整 Lua IO 库，读写路径受 Android 沙箱与存储权限约束。推荐用应用专属目录或授权后的公共目录：

-- 写文件（简单方式）
local f = assert(io.open("/sdcard/BriarLua/test.txt", "w"))
f:write("hello\n")
f:close()

-- 读文件：*a 全部 / *l 一行（默认） / n 数字
local g = io.open("/sdcard/BriarLua/test.txt", "r")
local all = g:read("*a")
g:close()

-- io.lines 逐行迭代
for line in io.lines("/sdcard/BriarLua/test.txt") do
  print(line)
end
工程实践中更推荐 require "utils.Project" 的 readFile / writeFile：自动 UTF-8 编码、自动建父目录、出错返回 nil 而不是抛异常。写 Android 11+ 公共目录（如 /sdcard/Download）需要 MANAGE_EXTERNAL_STORAGE 或分区存储 API。

操作系统（os）

os.time([table])

当前时间戳（秒）；传入 {year=,month=,day=,hour=,...} 表可换算指定时间。

os.date([fmt [, time]])

格式化时间：os.date("%Y-%m-%d %H:%M:%S")。!前缀用 UTC。

os.clock()

程序已用 CPU 时间（秒），用于性能测量。

os.getenv("PATH") / os.remove / os.rename / os.tmpname

环境变量与文件管理；在 Android 沙箱内部分功能受限。

os.exit([code]) / os.difftime(t2, t1)

退出（谨慎：会结束整个 Lua 状态）/ 时间差（秒）。

os.execute 在 Android 上基本不可用（无系统 shell 可调用），如需执行系统命令请改用 Java API（Runtime.exec）。

debug.getlocal / setlocal / getupvalue / setupvalue

读写局部变量与上值（编号从 1 开始）。

BriarLua 亦提供实用封装 printstack()（打印 1~16 层调用栈到日志页）与 dump(o)（递归打印任意表的树形结构，排环），两者均为全局函数。

导入模块

三种方式引入 Java 类与 Lua 模块：

local bindClass = luajava.bindClass

-- 1. luajava.bindClass：导入任意 Java 类（推荐，语义最明确）
local TextView = bindClass "android.widget.TextView"

-- 2. import()：把类以简名放进当前环境，自动搜索 java.lang / java.util / com.androlua 包
import "android.widget.Button"
local btn = Button(activity)

-- 3. require：加载 BriarLua 内建 Lua 模块（assets/lua 下）
local ProjectUtil = require "utils.Project"
local MyToast = require "utils.Toast"

import 还支持通配符与 dex：import "android.widget.*"（惰性包对象）、import "dex名:完整类名"。

不确定某个类的完整名字？在编辑器里选中类名，符号栏首格会显示完整类名，点击可"复制导入语句"或跳转 API 阅览器。全部可用类名见 API 阅览器（工具 → API阅览器）。

方法与属性

luajava 绑定的 Java 对象遵循以下访问规则：

方法调用

local btn = Button(activity)
btn.setText("确定")              -- 调用 Java 方法 setText(CharSequence)
btn.setText("确定", nil)      -- 多参重载按参数个数自动匹配

-- 返回值直接就是 Lua 值：int → number，String → string，boolean → boolean
local w = btn.getWidth()           -- number
local s = btn.getText().toString() -- CharSequence 通常需要再 toString

链式调用

返回自身的方法可以连续点下去（AndroLua 生态里 Builder 大量如此）：

local builder = MaterialAlertDialogBuilder(activity)
  .setTitle("标题")
  .setMessage("内容")
  .setPositiveButton("确定", nil)
builder.show()

静态成员与内部类

local View = bindClass "android.view.View"
btn.setVisibility(View.VISIBLE)     -- 静态常量直接点访问

-- 接口 / 内部类用 $ 连接
local listener = luajava.createProxy(
  "android.view.View$OnClickListener", { onClick = function(v) end })

属性访问

LuaBridge 同样暴露 getter/setter 风格属性：在布局表中 text = "..." 等价于 setText("...")，layout_width / layout_height / padding / id 等由 loadlayout 特殊处理。

Java 重载方法若参数类型不匹配会抛 LuaException；不确定时可先 pcall。null 参数用 nil 传递。

布局表

BriarLua 支持通过 Lua 表（Table）来构建 UI 布局，由 loadlayout() 函数加载：

local bindClass = luajava.bindClass
local LinearLayoutCompat = bindClass "androidx.appcompat.widget.LinearLayoutCompat"
local AppCompatTextView = bindClass "androidx.appcompat.widget.AppCompatTextView"

local layout = {
  LinearLayoutCompat,
  layout_width = -1,            -- match_parent；-2 为 wrap_content
  layout_height = -1,
  orientation = "vertical",      -- setOrientation 的字符串形式
  {
    AppCompatTextView,
    id = "myTitle",          -- 该控件将绑定为全局变量 myTitle
    text = "Hello BriarLua",
    textSize = "16sp",
    textColor = "#333333",
    padding = "8dp",
  }
}

-- views 表可接住全部 id 绑定（推荐：避免污染全局）
local views = {}
activity.setContentView(loadlayout(layout, views))
views.myTitle.setText("改标题")

常用属性速查：layout_width / layout_height（-1、-2 或 "100dp"）、layout_gravity / gravity、layout_weight、background（"#RRGGBB"、"?attr/名"、图片路径）、src、onClick（直接绑函数）。BriarLua 源码中的布局文件位于工程 assets/layout/ 目录，可作参考模板。

编辑器内置的布局文件（layout.editor / layout.setting 等）通过 loadlayout("layout.xxx") 按名字加载，加载后各 id 自动成为全局变量。

Canvas 绘图

绘图走标准 Android Canvas API，配合 BriarLua 内置的 com.androlua.LuaDrawable 可以把 Lua 函数变成 Drawable：

local bindClass = luajava.bindClass
local LuaDrawable = bindClass "com.androlua.LuaDrawable"
local Color = bindClass "android.graphics.Color"
local PorterDuff = bindClass "android.graphics.PorterDuff"

local drawable = LuaDrawable(function(canvas, paint)
  -- paint 由 LuaDrawable 提供；canvas 为 android.graphics.Canvas
  paint.setColor(Color.rgb(37, 99, 235))
  paint.setAntiAlias(true)
  canvas.drawCircle(200, 200, 120, paint)

  paint.setColor(Color.WHITE)
  paint.setTextSize(48)
  canvas.drawText("BriarLua", 120, 220, paint)
end)

-- 设为任意 View 的背景即可显示
myTitle.setBackgroundDrawable(drawable)

图片位图操作用 loadbitmap(path)（支持本地路径 / 网络地址）加载，配合 Canvas.drawBitmap、Matrix 变换。更多绘图类：Path、RectF、LinearGradient、BitmapShader 等均可直接 bindClass 使用。

若需每帧重绘（动画），在 LuaDrawable 回调里保存返回函数并配合 timer 定时 view.invalidate()；或改用 SurfaceView（API 阅览器搜索 SurfaceView）。

网络请求

两种方式，按需选用：

方式一：OkHttp 模块（推荐，HTTPS 友好）

local OkHttp = require "utils.OkHttp"

-- GET：showDialog 传 true 会显示进度对话框
OkHttp.get(true, "https://httpbin.org/get", {
  ["User-Agent"] = "BriarLua/1.8",
}, true, function(code, content, ms)
  -- 回调已在主线程：code 状态码（-1 为失败），content 响应体，ms 耗时
  if code == 200 then
    MyToast.short("请求成功 (" .. ms .. "ms)")
   else
    MyToast.short("请求失败: " .. tostring(content))
  end
end)

-- POST 表单 / JSON
OkHttp.post(false, "https://httpbin.org/post", {
  username = "GinHalion",
}, nil, function(code, content) print(content) end)

-- 文件上传：data 为字段表，file 为 { 字段名 = 文件路径 }
-- OkHttp.upload(true, url, data, file, header, callback)
OkHttp.cancelAllRequests()   -- 页面销毁时取消全部请求

方式二：LuaSocket（http 模块）

local http = require "http"
local ltn12 = require "ltn12"

local resp = {}
local ok, code, headers = http.request{
  url = "http://httpbin.org/get",
  sink = ltn12.sink.table(resp),
}
print(table.concat(resp))   -- 响应体
LuaSocket 是同步阻塞的，务必放在 task/thread 中执行；OkHttp 模块本身就是异步回调。另外应用需要声明 INTERNET 权限（BriarLua 已内置，打包时自动合并）。

事件与回调

在处理 Java 接口回调（如点击、触摸、动画等）时，必须使用 luajava.createProxy 绑定：

local btn = myButton
btn.setOnClickListener(luajava.createProxy(
  "android.view.View$OnClickListener", {
    onClick = function(v)
      MyToast.short("点击成功")
    end
  }))

部分框架组件也提供简化写法（loadlayout 属性 / LuaWebView 风格的 onKeyDown 全局函数）。同一接口的多个方法在表里并列即可，缺省方法回调返回 nil 等价 false：

myDrawerLayout.addDrawerListener(luajava.createProxy(
  "androidx.drawerlayout.widget.DrawerLayout$DrawerListener", {
    onDrawerSlide = function(v, offset) end,
    onDrawerOpened = function(v) MyToast.short("侧栏已打开") end,
    onDrawerClosed = function(v) end,
    onDrawerStateChanged = function(state) end,
  }))
回调在主线程触发，可以做 UI 操作；但不要在里面做耗时操作。页面销毁后晚到的回调可能因 LuaState 已关闭而报错——用 pcall 包裹最安全（框架源码统一这样做）。

线程与异步

三种异步工具，全部由框架提供，无需手写 Handler：

task —— 后台执行，回主线程拿结果

-- task(耗时函数, ..., 完成回调)：回调参数即函数返回值
task(function(path)
  -- 在线程池执行（可执行网络 / 大文件 / 重计算）
  local ok, err = pcall(function()
    return require("utils.Project").readFile(path)
  end)
  return ok, err
end, "/sdcard/BriarLua/project/demo/main.lua", function(content, err)
  -- 已切回主线程，可直接刷新 UI
  if content then myLuaEditor.setText(content) end
end)

thread —— 独立 Lua 线程

-- 传入字符串路径或函数；新线程有独立 LuaState，不能直接碰 UI
thread(function()
  for i = 1, 5 do
    print("子线程计数 " .. i)
    Thread.sleep(1000)
  end
end)

timer —— 定时 / 周期任务

-- timer(fn, 延迟ms, 周期ms)：周期 0 表示只执行一次
local t = timer(function()
  MyToast.short("每 2 秒触发一次")
end, 1000, 2000)

-- onDestroy 中 t.stop() 释放

原生写法（Java Handler，等价于以上）

local Handler = luajava.bindClass "android.os.Handler"
local Looper = luajava.bindClass "android.os.Looper"
local Thread = luajava.bindClass "java.lang.Thread"
local mainHandler = Handler(Looper.getMainLooper())

Thread(luajava.createProxy("java.lang.Runnable", {
  run = function()
    local result = "处理完成"
    mainHandler.post(luajava.createProxy("java.lang.Runnable", {
      run = function()
        myTextView.setText(result)
      end
    }))
  end
})).start()

核心 API

页面脚本通过 require "env" 自动获得以下全局对象与函数（BriarLua 全部页面已内置）：

全局 loadlayout(layout [, views])

加载布局表，返回 View 实例。views 传入空表可接收绑定的控件，避免全局污染。

全局 loadbitmap(path) / loadmenu(name)

加载图片（本地 / 网络）为 Bitmap；按名字加载菜单布局。

异步 task(fn, ..., callback) / thread(fn) / timer(fn, delay, period)

见线程与异步。

luajava luajava.bindClass(className)

导入并绑定一个 Java 类。

luajava luajava.newInstance(className, ...)

构造 Java 对象：luajava.newInstance("java.io.File", "/sdcard/")。

luajava luajava.createProxy(interfaceName, table)

创建 Java 接口的代理对象。常用在各类 OnClickListener 中。

luajava luajava.astable(javaArray)

将 Java 数组 / List 转为 Lua Table，常用于遍历文件列表。

工具 MyToast.short(text) / long / action(text, btn, fn)

Snackbar 提示（utils.Toast）。使用前先 MyToast.setActivity(activity)。

工具 MyActivity.new(name [, data])

打开内置页面：home / setting / editor / build / info / log / doc / api / parsing / analysis / welcome。

工具 MyColor.colorPrimary / colorOnSurface / ...

当前主题 Material 颜色（utils.Color），自动适配深浅色与动态取色。

工具 MyUI.setTitle(t) / dp2px(dp) / sp2px(sp)

界面小工具（utils.UI）：标题、单位换算、状态栏处理。

全局 copyText(content) / openUrl(url) / shareText(text)

剪贴板 / 打开浏览器 / 系统分享（mod.lua 内置）。

全局 backImage(name) / backHtml(name)

取内置资源绝对路径：res/drawable/名.png、res/html/名.html。

全局 dump(o) / each(javaIterable) / printstack()

调试打印：树形打印表 / 遍历 Java 集合 / 打印调用栈。

全局 print(...)

输出到日志页；独立线程中自动回退为 sendMsg。

全局 activity / service

当前上下文。activity.getLuaDir([sub]) 取 Lua 资源目录；getSharedData/setSharedData 读写应用偏好。

项目结构

BriarLua 在外部存储的固定工作目录为 /sdcard/BriarLua/：

/sdcard/BriarLua/
├── project/     -- 所有工程，一个文件夹一个工程
│   └── MyProject/
│       ├── init.lua      (打包配置，必须存在)
│       ├── main.lua      (入口代码)
│       ├── icon.png      (应用图标，可选)
│       └── res/          (工程自用资源，可选)
├── backup/      -- 工程备份
├── history/     -- 文件历史（编辑器撤销 / 版本记录）
└── bin/         -- 打包产物 APK 输出目录

这些路径也可在代码中获取：

local ProjectUtil = require "utils.Project"
print(ProjectUtil.project_path)   -- /sdcard/BriarLua/project
print(ProjectUtil.bin_path)       -- /sdcard/BriarLua/bin

-- 常用方法
ProjectUtil.readInit(projectDir)     -- 解析 init.lua 为配置表
ProjectUtil.listProjects()           -- 列出全部工程
ProjectUtil.writeFile(path, content) -- UTF-8 写文件
ProjectUtil.readFile(path)            -- UTF-8 读文件

打包发布

BriarLua 支持一键将工程打包为可安装的 APK 文件。

项目目录结构要求：

MyProject/
├── init.lua      (打包配置)
├── main.lua      (入口代码)
├── icon.png      (应用图标)
└── other.lua     (其他文件)

init.lua 完整字段（与框架解析一一对应）：

appname = "我的App"          -- 应用名称（必须）
packagename = "com.example.myapp" -- 包名（必须）
appver = "1.0"               -- 版本名
appcode = "1"                -- 版本号（整数递增）
minsdk = "23"                -- 最低 Android 6.0
appsdk = "35"                -- 目标 Android 15
debugmode = false            -- 打包时显示调试信息
user_permission = {            -- 追加权限，字符串数组
  "android.permission.CAMERA",
}
skip_compilation = {           -- 跳过 luac 编译的文件（保持源码分发）
  "script/dynamic.lua",
}

点击编辑器右上角的"打包"按钮，即可将工程编译生成 APK，产物存放在系统的 BriarLua/bin/ 目录下。生成的 APK 已使用统一密钥签名（v1+v2+v3），可直接安装或分发。
